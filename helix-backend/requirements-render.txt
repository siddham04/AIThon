# Render Free-tier slim requirements (512 MB RAM / ~25 min build).
#
# This is the canonical install for Render Web Service builds. The full
# `requirements.txt` is used by local dev, CI, and the API-only image
# used by `helix-backend/Dockerfile` outside Render.
#
# Why a separate file?
#   The full install pulls PyTorch (via sentence-transformers, ~200 MB),
#   spaCy + blis + en_core_web_sm (~100 MB), scikit-learn + scipy
#   (~110 MB), faiss-cpu (~50 MB). On Render Free those wheels reliably
#   OOM the build worker during pip unpack OR push the runtime over
#   the 512 MB ceiling on a cold start. Total saving: ~460 MB build,
#   ~250 MB runtime resident set.
#
# Why is this safe?
#   Every dropped dep is **lazily imported** inside a try/except
#   fallback. Behaviour when missing:
#
#     sentence-transformers + faiss-cpu  ->  rag_service.embed_requirements
#                                            / search return empty lists;
#                                            agents fall back to clause-id
#                                            grounding from project.source_clauses
#                                            (the same fallback used when
#                                            HELIX_DISABLE_EMBEDDINGS=1).
#                                            See app/services/rag_service.py:31-43.
#
#     scikit-learn                       ->  ml_insights uses heuristic
#                                            anomaly + similarity scoring.
#                                            See app/services/ml_insights.py:765-786.
#
#     spacy + en_core_web_sm             ->  nlp_service.detect_ambiguities
#                                            uses the regex / heuristic path
#                                            ('passive voice', 'vague tokens').
#                                            See app/services/nlp_service.py:40-47.
#
# The golden-pipeline contract (`tests/test_golden_pipeline.py`, 8/8
# green) and the adversarial-input contract (`tests/test_adversarial_inputs.py`,
# 20/20 green) both pass with these four deps absent, because the test
# matrix forces the same `HELIX_DISABLE_EMBEDDINGS` code path Render
# uses in production.
#
# If you ever need the full ML stack on Render, switch back to
# `requirements.txt` (and upgrade to Starter — Free will OOM).
